01

ขอบเขตของบริการ

MINT METAL เป็นระบบ ERP สำหรับธุรกิจและโรงงานเมทัลชีท รองรับกระบวนการขาย จัดซื้อ คลังวัตถุดิบ การผลิต และการส่งมอบ รวมถึงการจัดการข้อมูลสินค้าและสเปกตามคำสั่งซื้อ ทั้งนี้ ความสามารถที่ให้บริการขึ้นอยู่กับรูปแบบบริการ ความต้องการขององค์กร และขอบเขตที่ตกลงกันในใบเสนอราคาหรือเอกสารโครงการ

ฟังก์ชันหรือบริการบางรายการอาจไม่มีในทุกแพ็กเกจหรือทุกโครงการ รายละเอียดที่ใช้กับลูกค้าแต่ละรายให้ยึดตามเอกสารที่ตกลงกัน

02

รูปแบบการใช้บริการ

Subscription

เป็นบริการแบบเรียกเก็บค่าบริการเป็นรอบตามรูปแบบและขอบเขตบริการที่ตกลง โดย AlexiaSoft ให้บริการ Cloud Hosting มาตรฐาน พร้อม Backup การอัปเดตมาตรฐานตามขอบเขตบริการที่ระบุในแพ็กเกจ ใบเสนอราคา หรือข้อตกลงที่เกี่ยวข้อง และ Remote Support ในวันและเวลาทำการหรือช่วงเวลาบริการที่ตกลงกัน

License

เป็นการได้รับสิทธิ์ใช้ระบบตามขอบเขต License ที่ตกลง และรองรับการติดตั้งหรือปรับแต่งตามขอบเขตโครงการ การซื้อ License เป็นการได้รับสิทธิ์ใช้งานระบบตามขอบเขตที่ตกลง มิใช่การโอนกรรมสิทธิ์ในลิขสิทธิ์หรือ Source Code เว้นแต่มีข้อตกลงเป็นลายลักษณ์อักษรระบุไว้เป็นอย่างอื่น

03

ราคาและขอบเขตบริการ

ราคาอาจแตกต่างตามรูปแบบบริการ โมดูลที่เลือก และขอบเขตโครงการ ราคาเริ่มต้นที่แสดงบนเว็บไซต์ใช้เพื่อประกอบการพิจารณาเบื้องต้นเท่านั้น เงื่อนไขทางการค้าและค่าบริการสุดท้ายให้เป็นไปตามใบเสนอราคา คำสั่งซื้อ หรือข้อตกลงที่เกี่ยวข้อง

ความต้องการเฉพาะ งาน Customize หรืองานโครงการเพิ่มเติมอาจต้องให้ฝ่ายขายประเมินและเสนอราคาแยกตามขอบเขต

Add-on หรือบริการเพิ่มเติมให้เป็นไปตามรายการ ราคา และขอบเขตที่แสดงในเว็บไซต์หรือเอกสารทางการค้าที่เกี่ยวข้อง ณ เวลาที่ตกลงใช้บริการ

04

เงื่อนไข Subscription

บริการ Subscription รวม Cloud Hosting, Backup การอัปเดตมาตรฐานตามขอบเขตบริการที่ระบุในแพ็กเกจ ใบเสนอราคา หรือข้อตกลงที่เกี่ยวข้อง และ Remote Support ในวันและเวลาทำการหรือช่วงเวลาบริการที่ตกลงกัน งาน Customize, Integration, Migration, บริการ ณ สถานที่ และงานโครงการพิเศษอาจมีค่าใช้จ่ายเพิ่มเติม โดยพิจารณาจากขอบเขตงาน

ระยะเวลา การชำระเงิน การต่ออายุ และการยกเลิกบริการเป็นไปตามใบเสนอราคา คำสั่งซื้อ หรือข้อตกลงบริการของลูกค้าแต่ละราย

05

เงื่อนไข License

สิทธิ์ใช้งาน License เป็นไปตาม Standard Scope ที่ระบุในใบเสนอราคาหรือเอกสารโครงการ ค่าติดตั้งและตั้งค่าระบบคิดแยกต่างหาก และ License ไม่รวม Hosting / Server / Infrastructure เว้นแต่ระบุไว้ในใบเสนอราคา งาน Initial Configuration, Data Migration, Integration และ On-site work นอก Standard Scope รวมถึงงานปรับแต่งเพิ่มเติม ประเมินและเสนอราคาแยกตามขอบเขต

ตั้งแต่ปีที่ 2 การบำรุงรักษาและอัปเดตมาตรฐาน (MA) สำหรับ License คิดตามอัตราที่กำหนดจากมูลค่า License ที่ใช้งาน โดยเป็นไปตาม policy และใบเสนอราคาที่ตกลงกัน

06

งานปรับแต่งและการเชื่อมต่อระบบ

การปรับขั้นตอนการทำงานเพิ่มเติมตามขอบเขตโครงการ การเชื่อมต่อระบบหรือช่องทางข้อมูลตามขอบเขตโครงการและความสามารถของระบบที่เกี่ยวข้อง การย้ายข้อมูล รายงานเพิ่มเติม และงานเฉพาะโครงการต้องดำเนินการตามขอบเขตที่ตกลง การเปลี่ยนแปลงนอกขอบเขตอาจต้องประเมินเพิ่มเติม รวมถึงระยะเวลาและค่าใช้จ่ายเพิ่มเติม

งานเชื่อมต่อขึ้นอยู่กับข้อมูล เอกสาร ช่องทางหรือส่วนเชื่อมต่อที่มีอยู่ และความสามารถของระบบที่เกี่ยวข้อง โดยต้องผ่านการประเมินความเป็นไปได้และเป็นไปตามขอบเขตที่คู่สัญญาตกลงกัน

07

ความรับผิดชอบของลูกค้า

  • จัดเตรียมข้อมูลบริษัท ข้อมูลลูกค้า คู่ค้า สินค้า วัตถุดิบ และข้อมูลตั้งค่าที่เกี่ยวข้องให้ถูกต้องและเป็นปัจจุบัน
  • ดูแลบัญชีผู้ใช้ ข้อมูลเข้าสู่ระบบ และกำหนดสิทธิ์เข้าถึงให้เหมาะสม
  • ใช้งานระบบโดยชอบด้วยกฎหมายและไม่พยายามเข้าถึงส่วนที่ไม่ได้รับอนุญาต
  • ไม่คัดลอก จำหน่ายต่อ หรือเผยแพร่ซอฟต์แวร์เกินกว่าสิทธิ์ที่ได้รับ
  • ให้ความร่วมมือด้านการติดตั้ง การเชื่อมต่อ และการดำเนินโครงการตามที่จำเป็น
08

ข้อมูลและความเป็นส่วนตัว

การประมวลผลข้อมูลส่วนบุคคลเป็นไปตาม นโยบายความเป็นส่วนตัว ของ MINT METAL และข้อตกลงการประมวลผลข้อมูลเพิ่มเติมที่อาจใช้กับลูกค้าแต่ละราย

09

ทรัพย์สินทางปัญญา

ซอฟต์แวร์ MINT METAL รูปแบบการออกแบบ Source Code เครื่องหมายการค้า และทรัพย์สินทางปัญญาที่เกี่ยวข้องเป็นของ AlexiaSoft หรือผู้ทรงสิทธิ์ที่เกี่ยวข้อง ลูกค้าได้รับสิทธิ์ใช้งานตามบริการหรือ License ที่เลือกและขอบเขตที่ตกลง โดยไม่มีการโอนกรรมสิทธิ์ใน Source Code เว้นแต่จะตกลงเป็นลายลักษณ์อักษรโดยชัดแจ้ง

ข้อกำหนดนี้ไม่เปลี่ยนแปลงสิทธิ์ของลูกค้าในข้อมูลของลูกค้าเอง

10

การเปลี่ยนแปลงบริการและการอัปเดต

การอัปเดตมาตรฐานสำหรับ Subscription ให้เป็นไปตามขอบเขตบริการที่ระบุในแพ็กเกจ ใบเสนอราคา หรือข้อตกลงที่เกี่ยวข้อง ส่วนการอัปเดตและการสนับสนุนสำหรับ License เป็นไปตามขอบเขต MA หรือบริการสนับสนุนที่ยังมีผล การอัปเดตไม่ถือเป็นการรับรองว่าจะมีฟังก์ชันใหม่ทุกรายการ

การเปลี่ยนแปลงเงื่อนไขทางการค้าที่มีผลกับลูกค้าให้เป็นไปตามข้อตกลงที่ใช้กับลูกค้ารายนั้น
